1Agency Agents — 역할별 AI 전문가 모음

msitarzewski/agency-agents · 누적 152,731 · MIT

무엇을 해주나. 에이전트마다 한 분야의 전문가로 정해 둔 파일 모음입니다. 리포 표현으로는 각 에이전트가 성격·절차·검증된 산출물을 가진 전문가입니다.

어떻게 돌아가나. 파일 하나가 에이전트 하나입니다. 파일마다 정체성과 성격, 핵심 임무와 작업 순서, 코드 예시가 든 산출물, 성공 기준과 말투가 적혀 있습니다. 엔지니어링·디자인·영업·마케팅·보안 같은 부서별 폴더로 나뉘어 있고, 설치 스크립트가 그 파일들을 쓰는 도구의 자리로 옮겨 줍니다.

쓰면 좋은 사람. 「프런트엔드 개발자처럼」「보안 검토자처럼」 같은 역할 프롬프트를 매번 새로 쓰던 사람.

설치 방법 — 앱 (리포가 권하는 길)

  1. macOS·Linux·Windows 용 데스크톱 앱을 릴리스 페이지에서 받습니다.
  2. 앱에서 에이전트 목록을 둘러보고 고릅니다.
  3. 쓰는 도구(클로드 코드·커서·코덱스 등)를 골라 깔면, 앱이 업데이트도 맡습니다.

맥이라면 터미널 한 줄로도 앱을 깔 수 있습니다.

brew install --cask msitarzewski/agency-agents/agency-agents

설치 방법 — 스크립트 (클로드 코드)

  1. 리포를 내려받고 리포 폴더에서 터미널을 엽니다.
  2. 아래 줄로 전부 깔거나, 필요한 부서만 골라 깝니다.
  3. 클로드 코드 대화에서 역할을 불러 씁니다.
./scripts/install.sh --tool claude-code
./scripts/install.sh --tool claude-code --division engineering,security

부서와 에이전트 수를 먼저 보려면 이 줄입니다.

./scripts/install.sh --list teams

다른 도구(커서·오픈코드·코파일럿 등)는 변환 파일을 먼저 만들고 설치 마법사를 돌립니다.

./scripts/convert.sh
./scripts/install.sh
⚠️ 막히는 자리: 오픈코드는 지금 에이전트를 약 119개까지만 등록하고 나머지를 조용히 버립니다. 오픈코드에 깔 때는 --division 으로 부서를 골라 그 아래로 맞추세요 — 설치 스크립트도 넘을 때 경고합니다.
💡 설치 확인: 클로드 코드에 「Hey Claude, activate Frontend Developer mode and help me build a React component」 처럼 역할을 불러서, 그 역할의 말투와 순서로 답이 오면 걸린 겁니다.

2Agent-Reach — 에이전트에게 인터넷 읽는 눈

Panniantong/Agent-Reach · 누적 82,254 · MIT

무엇을 해주나. 에이전트가 웹페이지·유튜브·깃허브·RSS 를 읽고 검색하게 해 주는 능력층입니다. 리포 소개로는 CLI 하나에 API 요금이 없습니다(zero API fees). 리포 안에 한국어 README 도 있습니다.

어떻게 돌아가나. 플랫폼마다 「첫째 길 + 대체 길」을 순서대로 두고, 한 길이 막히면 다음 길로 넘어갑니다. 설치 직후에는 설정이 필요 없는 6개 채널만 켜지고, 로그인이 필요한 트위터·레딧·샤오홍슈·페이스북·인스타그램은 에이전트가 메뉴로 물어보고 고른 것만 켭니다. agent-reach doctor 가 채널마다 되는지, 지금 어느 길로 가는지 알려 줍니다.

쓰면 좋은 사람. 에이전트에게 링크를 줬다가 «못 읽어요»를 자주 듣던 사람, 조사·요약을 자주 시키는 사람.

설치 방법

  1. 쓰는 에이전트(클로드 코드·커서 등)의 채팅창을 엽니다 — 명령어가 아니라 프롬프트입니다.
  2. 아래 한 줄을 그대로 보냅니다. 에이전트가 설치 문서를 읽고 나머지를 합니다.
  3. 에이전트가 로그인이 필요한 채널을 물으면, 쓸 것만 고릅니다.
Install Agent Reach: https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md

이미 깔았다면 업데이트도 한 줄입니다(리포 본 README 의 중국어 문장 그대로).

帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md

기본 설치는 환경만 검사하고 시스템을 바꾸지 않습니다. 무엇을 할지 먼저 보거나, 시스템 설치까지 허락하려면 이 줄들입니다.

agent-reach install --env=auto --dry-run
agent-reach install --env=auto --system
⚠️ 막히는 자리: ① 오픈클로는 명령 실행 권한이 꺼져 있으면 설치가 안 됩니다 — 먼저 openclaw config set tools.profile "coding" 을 넣고 게이트웨이를 다시 켭니다. ② PyPI 에 같은 이름의 다른 패키지가 있습니다 — 리포에서 깔아야 합니다. ③ 쿠키로 로그인하는 채널은 계정이 막힐 위험이 있다고 리포가 적어 뒀습니다 — 본 계정 말고 따로 만든 계정을 쓰세요.
💡 설치 확인: 터미널에 agent-reach doctor 를 넣어 채널 상태를 봅니다. 지울 때는 agent-reach uninstall --dry-run 으로 먼저 무엇이 지워지는지 봅니다.

3Orca — 에이전트 여럿을 나란히

stablyai/orca · 누적 69,856 · MIT

무엇을 해주나. 코덱스·클로드 코드·오픈코드 같은 코딩 에이전트를 나란히 돌리고 한곳에서 봅니다. 리포 소개로는 에이전트를 내 구독 그대로 돌립니다.

어떻게 돌아가나. 에이전트마다 자기 git 워크트리를 줍니다. 그래서 프롬프트 하나를 다섯 에이전트에 보내고 결과를 비교해 이긴 쪽을 합칠 수 있습니다. 터미널 분할·편집기·내장 브라우저·diff 주석이 한 앱에 있고, 폰 앱은 에이전트가 끝나면 알려 주고 이어서 지시를 보냅니다. 터미널에서 도는 에이전트면 무엇이든 붙습니다.

쓰면 좋은 사람. 에이전트 창 여러 개를 오가다 무엇이 어디서 돌았는지 헷갈리던 사람, 같은 일을 여러 모델에 시켜 비교하고 싶은 사람.

설치 방법 — 데스크톱

  1. onorca.dev/download 에서 내 운영체제 판을 받습니다 (macOS·Windows (.exe)·Linux AppImage).
  2. 설치하고 저장소 폴더를 엽니다.
  3. 쓰는 에이전트를 골라 워크트리를 만들고 돌립니다.

패키지 매니저로도 깔 수 있습니다.

brew install --cask stablyai/orca/orca
yay -S stably-orca-bin

설치 방법 — 폰 앱

  1. iOS 는 App Store, 안드로이드는 README 의 APK 링크에서 받습니다.
  2. 데스크톱 앱과 짝을 맺습니다.
⚠️ 막히는 자리: Orca 는 에이전트를 대신 설치해 주지 않습니다 — 클로드 코드·코덱스 같은 CLI 에이전트가 먼저 깔려 있어야 합니다. 모니터 없는 리눅스 서버에서 돌리려면 README 의 orca serve 안내를 따로 봅니다.
💡 설치 확인: 같은 프롬프트로 워크트리 두 개를 만들어, 각 워크트리에서 에이전트가 따로 도는지 봅니다. 에이전트도 orca worktree create 같은 CLI 로 Orca 를 다룰 수 있습니다.

4OpenMontage — 코딩 에이전트를 영상 스튜디오로

calesthio/OpenMontage · 누적 59,438 · AGPL-3.0

무엇을 해주나. 쓰던 코딩 도우미를 영상 제작 스튜디오로 바꿉니다. 원하는 영상을 말로 적으면 에이전트가 조사·대본·소재 생성·편집·최종 합성을 맡습니다.

어떻게 돌아가나. 정해진 파이프라인을 따라 갑니다. 무료 경로도 있습니다 — 오프라인 음성(Piper), 공개 아카이브 영상(Archive.org·NASA·Wikimedia Commons), 렌더링(Remotion·HyperFrames·FFmpeg). 리포 표현으로 유료 API 키 없이도 실제 영상을 만들 수 있고, 키를 더할수록 쓸 수 있는 도구가 늘어납니다. 창작 결정마다 사용자 승인을 받습니다.

쓰면 좋은 사람. 짧은 설명 영상이나 자료 영상이 자주 필요한 사람. 라이선스가 AGPL-3.0 이라 회사 제품에 섞을 때는 조건을 먼저 확인하세요.

설치 방법

  1. 준비물을 확인합니다 — Python 3.10 이상 · FFmpeg · Node.js 18 이상 · 코딩 도우미(클로드 코드·커서·코파일럿·윈드서프·코덱스).
  2. 리포를 받고 설정을 돌립니다.
  3. 코딩 도우미로 그 폴더를 열고, 만들 영상을 말로 적습니다.
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup

첫 프롬프트는 리포 예시 그대로 써 보세요.

"Make a 60-second animated explainer about how neural networks learn"

윈도우에 make 가 없으면 PowerShell 에서 이 줄을 씁니다.

py -3 -m venv .venv; .\.venv\Scripts\Activate.ps1; python -m pip install -r requirements.txt; cd remotion-composer; npm install; cd ..; python -m pip install piper-tts; Copy-Item .env.example .env
⚠️ 막히는 자리: 윈도우에서 npm install 이 ERR_INVALID_ARG_TYPE 로 멈추면 npx --yes npm install 로 바꿉니다. API 키는 전부 선택이라 .env 에 가진 것만 넣으면 됩니다.
💡 설치 확인: python -m backlot open 으로 제작 보드를 열어, 파이프라인 단계가 켜지는지 봅니다.

5codebase-memory-mcp — 코드를 지식 그래프로

DeusData/codebase-memory-mcp · 누적 43,480 · MIT

무엇을 해주나. 코드베이스를 지식 그래프로 색인해 두고, 에이전트가 MCP 로 그 그래프에 묻게 합니다. 함수·클래스·호출 관계·HTTP 라우트가 노드와 선으로 남습니다.

어떻게 돌아가나. 이 도구 안에는 LLM 이 없습니다. 질문을 해석하는 건 지금 쓰는 에이전트이고, 이 도구는 그래프 질의만 돌려 결과를 돌려줍니다. 그래프 질의 한 번이 grep·파일 읽기를 수십 번 대신합니다. 처리는 전부 내 컴퓨터 안에서 일어나고 코드가 밖으로 나가지 않는다고 리포가 적어 뒀습니다. codebase-memory-mcp 자체 측정으로는 구조 질의 다섯 번이 약 3,400 토큰, 파일을 하나씩 뒤졌을 때 약 412,000 토큰으로 99.2% 줄었습니다.

쓰면 좋은 사람. 큰 저장소에서 에이전트가 파일 검색만 반복하다 토큰을 다 쓰던 사람.

설치 방법 — macOS · Linux

  1. 아래 한 줄을 터미널에 넣습니다.
  2. 코딩 에이전트를 껐다 켭니다.
  3. 에이전트에게 «Index this project» 라고 말합니다.
curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | bash

설치 방법 — Windows (PowerShell)

  1. 설치 스크립트를 받습니다.
  2. (권장) 메모장으로 열어 내용을 봅니다.
  3. 인터넷에서 받은 파일 표시를 풀고 실행합니다.
Invoke-WebRequest -Uri https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.ps1 -OutFile install.ps1
notepad install.ps1
Unblock-File .\install.ps1
.\install.ps1

클로드 코드에게 맡기려면 이 문장을 보냅니다.

Install this MCP server: https://github.com/DeusData/codebase-memory-mcp
⚠️ 막히는 자리: ① 스크립트 실행 정책 오류가 나면 Set-ExecutionPolicy -Scope Process Bypass 를 먼저 넣습니다. ② 마이크로소프트 디펜더가 Trojan:Script/Wacatac.B!ml 로 잡을 수 있는데, 리포는 이것을 알려진 오탐이라고 적고 직접 확인하는 방법을 SECURITY.md 에 뒀습니다. ③ 이 도구는 코드를 읽고 에이전트 설정 파일에 씁니다 — 리포가 그렇게 밝혀 뒀습니다.
💡 설치 확인: codebase-memory-mcp --ui=true --port=9749 로 띄운 뒤 브라우저에서 localhost:9749 를 열어 3D 그래프가 보이면 색인이 된 겁니다. 지울 때는 codebase-memory-mcp uninstall.
