0공통 — 한 줄 설치와 설치 확인

열 개 대부분이 npx skills 한 도구로 깔립니다. Node.js 가 깔려 있으면 됩니다.

npx skills add <owner/repo> --skill <스킬 이름>

기본은 지금 폴더(프로젝트)에 깔립니다. 모든 프로젝트에서 쓰려면 -g 를 붙입니다.

설치 확인

npx skills list

목록에 스킬 이름이 보이면 깔린 겁니다. 그다음 쓰는 도구를 껐다 켭니다.

⚠️ 막히는 자리: 클로드 코드에게 «설치해 줘» 라고 시키면, 설치기가 묻지 않고 돌아 .agents/skills/ 에만 깔 수 있습니다 — 클로드 코드는 그 폴더를 읽지 않습니다. 에이전트를 직접 지정하세요: -a claude-code
💡 npx skills 는 익명 사용 집계를 보냅니다. 끄려면 DISABLE_TELEMETRY=1 을 설정합니다.

1grill-with-docs — 설계를 캐묻기

mattpocock/skills · skills.sh 설치 991.6K · MIT

무엇을 해주나. 계획이나 설계를 두고 질문을 끝까지 이어 가면서, 그 자리에서 용어집(CONTEXT.md)과 결정 기록(ADR)을 채웁니다.

어떻게 돌아가나. 스킬 자체는 짧습니다 — grilling 과 domain-modeling 두 스킬을 차례로 부릅니다. 그래서 두 스킬이 같이 깔려 있어야 합니다.

쓰면 좋은 사람. 에이전트에게 바로 짜게 하기 전에 설계를 말로 굳히고 싶은 사람.

설치 방법

  1. 아래 줄을 터미널에 넣습니다. 설치기가 어느 스킬을 깔지 고르게 합니다.
  2. grill-with-docs · grilling · domain-modeling 과 setup-matt-pocock-skills 를 고릅니다.
  3. 도구를 껐다 켜고 /grill-with-docs 로 부릅니다.
npx skills@latest add mattpocock/skills
⚠️ 막히는 자리: grill-with-docs 하나만 고르면 부를 스킬 둘이 없어 제대로 안 돕니다. 리포도 setup-matt-pocock-skills 를 꼭 같이 고르라고 안내합니다.

2vercel-react-best-practices — React 성능 규칙

vercel-labs/agent-skills · skills.sh 설치 721.1K

무엇을 해주나. React·Next.js 성능 규칙 70개를 8개 분야로 묶어, 코드를 쓰거나 리뷰할 때 에이전트가 참고하게 합니다.

어떻게 돌아가나. 영향이 큰 순서로 분야를 나눴습니다 — 요청 대기(waterfall) 없애기와 번들 크기 줄이기가 가장 급한 칸이고, 규칙마다 async-·bundle- 같은 앞말이 붙습니다.

쓰면 좋은 사람. React 컴포넌트·Next.js 페이지를 새로 쓰거나 성능 리뷰를 하는 사람.

설치 방법

npx skills add vercel-labs/agent-skills --skill vercel-react-best-practices
⚠️ 막히는 자리: --skill 에는 폴더 이름(react-best-practices)이 아니라 스킬 이름(vercel-react-best-practices)을 적습니다.
💡 설치 확인: npx skills list 에 vercel-react-best-practices 가 보이면 됩니다.

3supabase-postgres-best-practices — Postgres 규칙

supabase/agent-skills · skills.sh 설치 404.8K · MIT

무엇을 해주나. Supabase 가 관리하는 Postgres 규칙 모음입니다. Supabase 가 아니어도 Postgres 면 어디서든 씁니다.

어떻게 돌아가나. 규칙을 8개 분야로 나눴고, 쿼리 성능 · 연결 관리 · 보안과 RLS 가 가장 급한 칸입니다. 테이블·인덱스·마이그레이션·RLS 정책을 만지기 전에 불리도록 적혀 있습니다.

쓰면 좋은 사람. SQL 을 쓰거나 스키마·RLS 를 자주 고치는 사람.

설치 방법

npx skills add supabase/agent-skills --skill supabase-postgres-best-practices

클로드 코드 플러그인으로도 깔 수 있습니다.

claude plugin marketplace add supabase/agent-skills
claude plugin install postgres-best-practices@supabase-agent-skills
⚠️ 막히는 자리: 플러그인 이름은 postgres-best-practices 로 스킬 이름과 다릅니다. 두 방법을 겹쳐 깔지 마세요.

4brainstorming — 짜기 전에 합의

obra/superpowers · skills.sh 설치 365.7K · MIT

무엇을 해주나. 무언가 만들기 전에 의도·요구사항·설계를 먼저 묻고, 사람이 승인하기 전에는 코드를 쓰지도, 프로젝트를 만들지도 않게 합니다.

어떻게 돌아가나. 첫 질문 전에 요청의 크기를 분류해 소리 내어 말합니다. 작은 일이면 짧은 설계로, 큰 일이면 스펙 문서로 갑니다 — 절차 길이는 달라도 승인 관문은 늘 있습니다.

쓰면 좋은 사람. 에이전트가 묻지도 않고 바로 짜기 시작하는 게 불안한 사람.

설치 방법 — 클로드 코드 (Superpowers 전체)

/plugin install superpowers@claude-plugins-official

설치 방법 — 스킬 하나만

npx skills add obra/superpowers --skill brainstorming
⚠️ 막히는 자리: brainstorming 은 끝에 writing-plans 스킬로 넘어갑니다. 하나만 깔면 그 다음 단계가 비어서, 흐름 전체를 쓰려면 플러그인 쪽이 낫습니다.

5ui-ux-pro-max — 디자인 자료 검색

nextlevelbuilder/ui-ux-pro-max-skill · skills.sh 설치 360.0K · MIT

무엇을 해주나. 화면을 설계·리뷰할 때 스타일·팔레트·폰트 조합·UX 규칙을 내 컴퓨터 안에서 검색해 골라 줍니다.

어떻게 돌아가나. 규칙을 10개 분야로 나눠 우선순위를 매겼고, 접근성과 터치 조작이 가장 급한 칸입니다. 검색은 파이썬 스크립트가 돌리고 네트워크를 쓰지 않습니다.

쓰면 좋은 사람. 디자이너 없이 화면 모양을 정해야 하는 개발자.

설치 방법 — 클로드 코드

  1. 아래 두 줄을 차례로 보냅니다.
  2. 새 대화를 엽니다.
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill

설치 방법 — 다른 도구

npx skills add nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max
⚠️ 막히는 자리: 검색 스크립트에 Python 3 이 필요합니다. 없으면 python.org 나 OS 패키지 관리자로 먼저 깝니다.

6brandkit — 브랜드 보드 한 장

Leonxlnx/taste-skill · skills.sh 설치 297.7K · MIT

무엇을 해주나. 로고 시스템·색·서체·목업을 담은 브랜드 가이드 보드를 이미지 한 장으로 만들게 합니다.

어떻게 돌아가나. 이미지 생성용 스킬입니다. 흔한 로고, 아무렇게나 깐 목업, 어수선한 무드보드를 금지하고 여백·위계가 선 판을 요구합니다.

쓰면 좋은 사람. 새 서비스의 첫 브랜드 시안이 급한 사람.

설치 방법

npx skills add https://github.com/Leonxlnx/taste-skill --skill "brandkit"
⚠️ 막히는 자리: --skill 값은 폴더 이름이 아니라 SKILL 안의 name: 값입니다. 이 묶음의 기본 스킬은 이름이 design-taste-frontend 입니다.
💡 이미지 생성 도구가 붙은 에이전트에서 써야 결과가 나옵니다.

7impeccable — 화면 다듬기

pbakaus/impeccable · skills.sh 설치 280.4K · Apache-2.0

무엇을 해주나. 스킬 하나에 명령 24개(polish·audit·critique 등)로 프런트엔드 화면을 만들고 다듬습니다.

어떻게 돌아가나. /impeccable init 이 제품 정보를 PRODUCT.md 에 적어 두고, 이후 명령이 그걸 읽습니다. 검출 규칙 61개가 모든 모델에서 반복되는 «AI 화면 티»를 잡는데, 이 규칙은 LLM·API 키 없이 돕니다.

쓰면 좋은 사람. 만드는 화면이 다 비슷해 보여 고민인 사람.

설치 방법

  1. 프로젝트 폴더에서 아래 줄을 넣습니다. 깔린 도구를 찾아 보여 줍니다.
  2. 쓰는 도구 안에서 /impeccable init 을 부릅니다.
npx impeccable install

업데이트는 이 줄입니다.

npx impeccable update
⚠️ 막히는 자리: 코덱스는 설치·업데이트 뒤 /hooks 를 열어 프로젝트 훅을 승인해야 합니다.

8seo-audit — SEO 점검

coreyhaines31/marketingskills · skills.sh 설치 208.8K · MIT

무엇을 해주나. 사이트의 SEO 문제를 찾아 고칠 거리를 정리합니다.

어떻게 돌아가나. 크롤링·색인 → 기술 기반 → 페이지 요소 → 콘텐츠 품질 → 권위·링크 순서로 봅니다. 구조화 데이터는 curl 같은 단순 요청으로는 안 보일 수 있어 브라우저 도구로 확인하게 합니다.

쓰면 좋은 사람. 검색 유입이 줄었거나 «왜 구글에 안 뜨지» 가 궁금한 사람.

설치 방법

npx skills add coreyhaines31/marketingskills --skill seo-audit -a claude-code
⚠️ 막히는 자리: 에이전트 안에서 설치를 시키면 클로드 코드가 안 읽는 폴더에 깔릴 수 있어 -a claude-code 를 붙였습니다. 제품 정보 파일(.agents/product-marketing.md)이 있으면 먼저 읽습니다.

9browser-use — 브라우저 직접 조작

browser-use/browser-use · skills.sh 설치 94.9K · MIT

무엇을 해주나. 에이전트가 CDP 로 브라우저를 직접 움직여 클릭·입력·이동·스크린샷을 합니다.

어떻게 돌아가나. 클릭·입력이 필요하거나, 로그인한 세션·자바스크립트 렌더링이 필요할 때만 켭니다. 공개 페이지를 읽기만 하면 브라우저를 켜지 않습니다. 로그인 벽에서는 멈추고 사람에게 묻습니다.

쓰면 좋은 사람. 연동 API 가 없는 사이트 작업을 에이전트에게 맡기고 싶은 사람.

설치 방법

리포가 권하는 방법은 아래 문장을 에이전트 채팅에 그대로 붙여 넣는 것입니다.

Install or upgrade browser-use to the latest stable version with uv using Python 3.12, run `browser-use skill install` to register the skill, and connect it to my browser.

스킬만 따로 깔려면 이 줄입니다.

npx skills add browser-use/browser-use --skill browser-use
⚠️ 막히는 자리: 스킬은 browser-use 명령(CLI)을 부릅니다. 스킬만 깔고 CLI 가 없으면 돌지 않습니다 — uv 와 Python 3.12 가 먼저입니다.

10shadcn — 컴포넌트 붙이기

shadcn-ui/ui · MIT · skills.sh 설치 — shadcn/ui 줄 271.7K · shadcn-ui/ui 줄 62.5K (두 줄 따로)

무엇을 해주나. shadcn/ui 컴포넌트를 찾고, 추가하고, 고치고, 조합하는 일을 에이전트가 프로젝트에 맞게 하게 합니다.

어떻게 돌아가나. components.json 이 있는 프로젝트에서 켜지고, 매번 shadcn info --json 으로 프레임워크·설치된 컴포넌트를 읽습니다. 있는 컴포넌트를 먼저 쓰고, 폼은 FieldGroup, 색은 시맨틱 색으로 맞춥니다.

쓰면 좋은 사람. shadcn/ui 로 화면을 만드는 사람.

설치 방법

pnpm dlx skills add shadcn/ui

npm 을 쓰면 이 줄입니다.

npx skills add shadcn-ui/ui --skill shadcn
⚠️ 막히는 자리: 프로젝트에 components.json 이 없으면 스킬이 켜지지 않습니다. shadcn 을 아직 안 깐 프로젝트라면 npx shadcn@latest init 부터입니다.
