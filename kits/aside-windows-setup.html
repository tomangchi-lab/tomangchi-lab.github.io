🧰 Aside 윈도우 설치 순서
받기 → 내 구독 연결 → CLI → 클로드 코드

AI 브라우저 Aside 의 윈도우 정식판이 나왔습니다. 받아서 여는 것보다 이미 내는 클로드·챗GPT 구독을 붙이는 자리와 터미널·클로드 코드에 잇는 자리에서 막히기 쉬워, 그 네 단계를 순서대로 적고 각 단계의 막히는 자리를 붙였습니다. 설치 줄과 메뉴 이름은 공식 도움말 그대로입니다.

0먼저 — 이 글은 광고가 아닙니다

대가·제휴 없이 저희가 직접 받아 보고 적은 순서입니다. 요금은 aside.com 요금 페이지 기준으로, 무료 요금제에 «Bring your own subscription» 이 들어 있어 내 구독만 붙이면 값을 더 내지 않고 돌릴 수 있습니다.

단계어디서막히는 자리
1 받기aside.com → Download복구 키 파일을 어디 두나
2 내 구독 연결Settings > Models > ProvidersOAuth 팝업이 닫힌 뒤 돌아오기
3 CLISettings › Developers먼저 열어 둔 터미널은 못 찾는다
4 클로드 코드터미널 한 줄스킬을 깐 뒤 aside guide 부터
💡 순서를 바꾸지 마세요. CLI 는 앱이 떠 있어야 말을 듣고, 구독은 앱 안에서만 붙습니다.

1받기 — 윈도우판 설치

무엇을 받나. aside.com 의 Download 에서 윈도우 설치 파일을 받습니다. 변경 로그 v1.0.914.1 첫 줄이 «Aside is now officially available on Windows!» 입니다.

첫 실행에서 묻는 것. 비밀번호 관리자(Aside Vault)를 켤지 묻고, 켜면 복구 키를 파일로 내려 줍니다. 그 다음이 «AI 구독 선택» 화면이고, 이건 2단계에서 붙입니다.

⚠️ 막히는 자리: 복구 키 파일이 기본으로 다운로드 폴더에 떨어집니다. 그 폴더는 나중에 통째로 지우기 쉬우니, 비밀번호 관리자나 외장 저장소로 옮기고 다운로드 폴더의 사본은 지우세요. 키를 잃으면 금고를 다시 열 수 없습니다.
💡 다른 브라우저의 북마크·비밀번호 가져오기는 온보딩에 있습니다. 실패하면 대화 상자로 알려 줍니다.

2내 구독 연결 — 클로드·챗GPT 그대로

무엇을 해주나. Aside 크레딧 대신 이미 내는 구독의 모델로 에이전트를 돌립니다. 도움말이 적어 둔 대상은 셋입니다.

  • Claude Subscription — reuse your Claude Pro or Max subscription
  • ChatGPT Subscription — reuse your ChatGPT Plus or Pro subscription
  • GitHub Copilot — reuse your GitHub Copilot subscription

연결 방법

  1. 앱에서 Settings > Models > Providers 를 엽니다.
  2. Connect 를 누르고 Subscription 아래에서 제공자를 고릅니다.
  3. OAuth 로그인 팝업이 뜹니다. 로그인을 끝내고 Aside 로 돌아옵니다.
⚠️ 막히는 자리: 팝업에서 로그인을 끝냈는데 목록에 안 보이면, 앱으로 돌아오지 않은 채 팝업만 닫은 경우가 많습니다. Providers 목록에 «Subscription» 라벨이 붙은 줄이 생겼는지 보세요.
💡 붙인 구독은 Aside 크레딧과 따로 셉니다. 무료 요금제의 월 500 크레딧은 Aside 자체 모델을 쓸 때만 줄어듭니다. API 키(Anthropic · OpenAI · OpenRouter · Google · xAI 등)를 넣는 길도 같은 화면에 있습니다.

3CLI — 터미널에서 aside 한 줄

무엇을 해주나. 터미널에서 aside "할 일" 로 브라우저 에이전트를 부르고, 코딩 도구에 MCP 서버로 붙일 수 있게 합니다.

설치 방법 — 윈도우

  1. 앱에서 Settings > Developers 를 엽니다.
  2. Install 버튼을 누릅니다. 설정 페이지가 설치·업데이트·재설치를 직접 해 줍니다.
  3. 새 터미널을 엽니다. 그 다음 아래 줄로 확인합니다.
aside --version

설치 방법 — 맥·리눅스

curl -fsSL https://releases.aside.com/install.sh | bash
⚠️ 막히는 자리: 설치 전에 열어 둔 터미널·에디터는 aside 를 못 찾습니다. PATH 가 새 창부터 반영되기 때문이라, 새 터미널을 여세요. 그래도 안 되면 윈도우에서는 사용자 폴더 아래 AppData\Local\Aside\CLI\current 안의 aside.exe 를 전체 경로로 부르면 됩니다.
💡 CLI 는 앱이 떠 있어야 동작합니다. 앱을 끄면 «Aside isn't running on this machine» 이 뜹니다. 판이 낡았으면 아래 한 줄로 올립니다.
aside update

4클로드 코드 — 스킬로 얹기

무엇을 해주나. 클로드 코드·코덱스·커서·오픈코드 안에서 «브라우저로 이거 해 줘» 라고 하면 Aside 가 대신 브라우저를 움직입니다. 변경 로그의 문장 그대로, aside skills install 이 그 도구들에 aside-browser 스킬을 깔아 줍니다.

설치 방법

  1. 터미널에서 아래 한 줄을 보냅니다. 어느 도구에 깔지 물어보면 고릅니다.
  2. 깐 도구(클로드 코드 등)를 새로 엽니다.
  3. 그 도구 안에서 먼저 aside guide 를 읽게 합니다. 스킬 파일이 «반드시 먼저 읽으라»고 적어 둔 그 줄입니다.
aside skills install
aside guide

MCP 로 붙이는 도구면 mcp.json 에 명령을 aside mcp 로 적습니다. 설정 페이지가 CLI 의 실제 경로를 찾아 줬으면 그 경로를 command 에 넣습니다.

⚠️ 막히는 자리: 스킬은 «문»일 뿐이라 실제 사용법은 aside guide 출력에 있습니다. 그걸 건너뛰면 도구가 명령을 추측해 엉뚱한 옵션을 씁니다. 화면을 직접 들여다봐야 하는 일(스크린샷 · DOM)은 aside repl 인데, 그 전에 aside guide repl 을 먼저 읽으라고 적혀 있습니다.
💡 설치 확인: 클로드 코드에서 «브라우저로 aside.com 요금 페이지 열어서 무료 요금제 항목 읽어 줘» 를 시켜 보세요. Aside 창에 Agent Tabs 그룹이 생기며 탭이 열리면 걸린 겁니다.

5순서 체크리스트

  • aside.com 에서 윈도우판을 받아 설치했다
  • 복구 키 파일을 다운로드 폴더 밖으로 옮겼다
  • Settings › Models › Providers 에 «Subscription» 줄이 생겼다
  • Settings › Developers 에서 CLI 를 깔고 새 터미널에서 aside --version 이 찍힌다
  • aside skills install 뒤 도구를 새로 열고 aside guide 를 읽게 했다
