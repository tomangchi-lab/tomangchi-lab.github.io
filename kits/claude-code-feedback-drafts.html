feedbackDrafts 켜고 끄기

이 장은 손이 먼저 가는 순서로 놓았습니다 — 끄는 법, 다시 켜는 법, 초안이 쌓이는 자리를 직접 여는 법, 그리고 보내기 전에 반드시 볼 것. 저희가 조회한 값은 뒤에 있습니다.

⚡ SendFeedback 을 끄는 스위치는 feedbackDrafts 하나입니다. 초안은 ~/.claude/feedback/drafts/ 에 쌓이고, /feedback 에서 보고 승인해야 나갑니다.

1끄는 법 — 붙여 넣는 설정

릴리스 노트가 「turn off with the feedbackDrafts setting」이라고 적은 그 스위치입니다.
파일
사용자 전체면 ~/.claude/settings.json, 이 프로젝트만이면 .claude/settings.json
{
  "feedbackDrafts": false
}
다시 켜려면
true 로 바꾸거나 그 줄을 지웁니다
🔴 settings.json 은 BOM 없는 UTF-8 로 저장하세요. BOM 이 붙으면 파일 전체가 파싱에 실패해 다른 설정까지 통째로 무시됩니다. 저희가 실제로 겪은 사고입니다.

2쌓인 초안 직접 열어 보기

경로는 로컬 설치본 2.1.247 에서, 상한과 만료는 공식 도구 문서에서 읽은 값입니다.
쌓이는 곳
~/.claude/feedback/drafts/ — UUID 이름의 파일
한 세션 카드 상한
3장 — 그 뒤로는 대기열 개수만 보입니다 (feedbackDrafts 를 quiet 로 두면 처음부터 개수만)
큐에 두면
30일 뒤 만료됩니다
ls ~/.claude/feedback/drafts/
cat ~/.claude/feedback/drafts/<파일이름>
비우려면
그 폴더의 파일을 지우면 됩니다. 지우기 전에 한 번 열어 보세요 — 무엇이 들어갔는지는 파일이 말해 줍니다

4보내기 전에 볼 것

🔴 리포트만 가지 않습니다 — 보고 본문 · 환경 정보(판본·운영체제·모델) · 최근 API 요청 ID 가 함께 갑니다. 대화 트랜스크립트는 검토 화면의 토글이고 기본값이 「보냄」입니다. 사내 코드나 비공개 자료를 다루던 세션이면 그 자리를 보고 보내세요.
카드에서 바로 보내면
트랜스크립트는 가지 않습니다 — 문서 원문 「Sending from the card never includes the transcript」
검토 화면에서 보내면
Send transcript 가 yes 로 시작합니다. no 로 바꾸면 보고서만 갑니다
이름이 말해 줍니다
/bug 의 설명이 「Report a bug or share your conversation」입니다
공식이 모은다고 적은 것
사용 데이터(코드 수락·거절 등) · 연관된 대화 데이터 · /bug 으로 보낸 피드백
반대쪽도 적혀 있습니다
민감 정보 보관 기간 제한 · 세션 데이터 접근 제한 · 그리고 모델 학습에 쓰지 않는다(「clear policies against using feedback for model training」)
실무 요령
보내기 화면에서 설명문을 고칠 수 있습니다. 경로·사내 식별자가 보이면 그 자리에서 지우고 보내세요

5초안이 써지는 때

공식 도구 문서 기준입니다 — 발표문은 셋으로 요약했지만 문서는 넷입니다. 「버그」만이 아닙니다.
① 도구·명령이 계속 실패
A tool or command keeps failing
② 요청을 못 들어줄 때
It can't help with something you asked for
③ 지적받거나 스스로 알아차림
You point out a mistake it made, or it notices one
④ 사람이 신고해 달라고 함
You ask it to file feedback
초안 종류
bug · idea · missing_capability

6저희가 하지 않은 것

못 잡는 것을 잡는 척하지 않습니다.
초안 생성
일부러 안 했습니다. 시연용으로 하나 만들면 그게 실제 대기열에 쌓이고, 잘못 승인되면 진짜로 전송됩니다
전송
같은 이유로 안 했습니다
환경변수 3종
설치본에는 있으나 공식 설정 문서에 없어 뺐습니다. 문서화된 feedbackDrafts 만 실었습니다
확인한 범위
판본 · 명령 실물과 설명 문구 · 저장 경로 · 차단 설정까지입니다. 계기·동봉 항목·상한은 공식 도구 문서를 정본으로 삼았습니다
설치본의 「10건」
설치본에서는 10 이라는 값을 읽었지만 공식 문서에 같은 상한이 없어 카드에서 뺐습니다. 문서가 말하는 축은 카드 3장 · 30일 만료로 다릅니다
