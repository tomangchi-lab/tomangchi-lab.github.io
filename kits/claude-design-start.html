🎨 Claude Code /design
시작 가이드

코딩 도구 안에서 시안을 뽑고, 고르고, 그대로 구현까지 넘기는 기능입니다. 공식 문서와 공식 발표에 있는 것만 적었고, 확인 안 된 건 넣지 않았습니다.

1시작하기

먼저 최신 버전으로 올립니다.

claude update

되는 곳 — 공식 발표 기준 CLI(터미널)와 Claude Code 데스크톱 앱입니다. 발표 영상 끝 화면에는 Claude Tag까지 세 곳이 표시됩니다.

원문
“from CC Desktop or CLI, try something like "/design a few options for {feature}" before you build — pick your fave artboard, edit it and implement.” — @nateparrott (Anthropic, Claude Design 제작자)
💡 /design은 대화형 터미널에서 엽니다. 저희가 스크립트 실행(claude -p) 경로로 넣어 보니 아트보드가 뜨지 않고 일반 프롬프트로 처리됐습니다 — 직접 확인한 결과입니다.

2첫 문장은 이렇게

형식은 /design + 만들려는 화면입니다. 공식 예시 형태가 /design a few options for {기능}이고, 한국어로 써도 됩니다.

/design 로그인 화면 시안 몇 개 /design 설정 페이지 — 밀도만 다르게 3안 /design 온보딩 체크리스트, 단계는 5개 이하로 /design 결제 실패 안내 모달 — 톤 다르게 2안 /design 대시보드 상단 요약 카드 배치안

“몇 개”, “~안”처럼 가짓수를 적으면 비교할 수 있는 시안이 나옵니다. 공식 예시 문장 자체가 “a few options”입니다.

💡 코드베이스를 읽어 기존 UI 스타일에 맞춘다고 공식 발표가 밝힙니다 — 프로젝트 폴더 안에서 실행하세요.

3시안이 나온 다음 — 다시 뽑지 마세요

설계 의도가 “가장 마음에 드는 것을 고르고, 그것을 직접 고친다”입니다. 마음에 안 든다고 통째로 재생성하는 흐름이 아닙니다.

원문
“Run /design to get editable artboards for your UI — pick one, tweak it, then have Claude implement it.” — @ClaudeDevs 공식 발표

고치는 방법 (claude.com/product/design 기준)

  • 요소에 코멘트 달기
  • 텍스트 직접 편집
  • Claude가 만들어 주는 조절 슬라이더로 간격·색 맞추기
  • 레이아웃 컨트롤 — 끌어서 옮기기, 크기 조절, 정렬
💡 편집한 내용은 Save를 눌러야 반영됩니다 — 제작자가 “지금은 Save를 눌러 주세요, 곧 안 눌러도 되게 만들겠습니다”라고 답글로 밝혔습니다(@nateparrott). 공식 문서에는 이 항목이 없어 제작자 발언으로 표기합니다.

4구현으로 넘기기

시안과 코드가 같은 세션에서 이어집니다. 파일로 내보내 붙여넣는 과정이 필요 없습니다.

  1. /design으로 아트보드를 받는다
  2. 마음에 드는 안을 고르고 그 자리에서 고친다
  3. 구현해 달라고 말하면 Claude가 실제 코드 파일을 고친다
원문
“Claude reads your codebase, matches the UI style, and makes shareable mocks in an Artifact.” — @nateparrott
“The new /design skill (research preview) brings Claude Design's artboard workflow into the CLI and Desktop, built on artifacts.” — @ClaudeDevs

결과 시안은 Artifact(claude.ai의 링크 페이지)로 만들어져 공유됩니다. 터미널에서 Ctrl+]를 누르면 최근 아티팩트를 다시 엽니다.

⚠️ 안 되는 조건 — 여기서 막힙니다

아트보드가 Artifact 기능 위에 올라가 있어서, 아티팩트가 막히는 조건에서는 /design도 결과물을 못 냅니다. 아래는 전부 공식 문서(code.claude.com/docs/en/artifacts)에 적힌 요건입니다.

“Customer-managed encryption keys (CMEK), HIPAA, and Zero Data Retention are not enabled for the organization.”

회사 계정에서 안 열리면 대개 이 표의 아래 세 줄 중 하나입니다. Enterprise는 관리자가 아티팩트를 켜야 합니다.

📌 더 알아두면 좋은 것

  • 리서치 프리뷰입니다 — 공식 발표가 그렇게 밝힙니다. 동작과 화면이 바뀔 수 있습니다.
  • 추가 요금은 없습니다. 대신 사용량을 채팅·Claude Cowork·Claude Code와 함께 씁니다(claude.com/product/design).
  • 공유 범위가 플랜마다 다릅니다. Pro·Max는 공개 링크가 유일한 공유 수단이고, Team·Enterprise는 조직 내 공유가 됩니다.
  • 디자인 시스템을 읽힙니다. 프로젝트의 CLAUDE.md나 테마 파일에 색·서체·간격을 적어 두면 Claude가 그것을 우선합니다.
  • 새 아티팩트는 처음에 나만 봅니다. 게시 전에 Claude가 권한을 한 번 묻고, 이후 같은 아티팩트 갱신은 다시 묻지 않습니다.
