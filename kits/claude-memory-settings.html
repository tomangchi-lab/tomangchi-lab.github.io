Claude 메모리 설정 3분 가이드

8월 25일부터 Claude 의 채팅 메모리와 Cowork 메모리가 하나입니다. 무엇을 기억할지는 내가 정합니다 — 필요한 화면은 Settings > Memory 하나입니다.

⚡ Settings > Memory — 여기서 읽고, 고치고, 지우고, 멈춥니다.

1보기 · 고치기 · 지우기

카드 02 는 이것을 말로 옮긴 것이고, 아래가 원문 기준 경로입니다.
어디에
Settings > Memory → Topics 아래에 주제별 파일이 한 줄씩 있습니다(Profile·Preferences 는 «You» 묶음).
읽기
파일을 열면 요약 한 줄과 세부 항목이 보입니다. 짧습니다.
편집
파일 하나를 고치면 그 뒤 모든 대화에 반영됩니다 — 회사 옛 이름을 고치는 식.
삭제
파일 오른쪽 휴지통. 주제 하나만 지울 수 있습니다.
일시정지 · 초기화
메모리 전체를 잠시 멈추거나 전부 초기화할 수 있습니다 — 언제든.
언제 적히나
대화가 끝난 뒤 요약이 아니라 말하는 중에 추가됩니다. «마감이 9월로 밀렸다»고 말하면 다음 대화가 이미 압니다.

2민감한 주제는 내가 고른다

토글 이름 그대로 — Include sensitive topics in memory.
기본값
꺼짐. 건강 · 인종 · 민족 · 종교적 신념 · 정치 · 성 정체성 같은 주제는 저장하지 않습니다.
켜면
글루텐 알레르기처럼 매번 다시 말하기 귀찮은 것을 기억합니다. 저장할 때마다 알림이 오고, 켜기 전 대화는 소급 저장되지 않습니다.
켜도 안 남기는 것
SSN·정부 발급 ID 같은 식별번호 · 범죄 이력 · 이민 신분 · AUP 위반 내용. 이때는 Claude 가 «메모리에 못 넣는다»고 알려 줍니다.
