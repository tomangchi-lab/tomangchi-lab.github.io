클로드 스킬 시작 가이드

터미널 없이 웹에서 켜는 것부터, 남이 만든 스킬을 가져다 쓰는 것까지. 10분 안에 첫 스킬이 돌아가게 하는 것이 이 문서의 목표입니다.

1웹에서 켜기 — 2단계

순서가 중요합니다. 1단계를 건너뛰면 스킬 메뉴 자체가 나타나지 않습니다.

1단계 — 코드 실행 켜기

Settings→Capabilities→Code execution and file creationON

2단계 — 스킬 목록에서 토글

Customize/사용자 지정→Skills/스킬→개별 스킬ON
한국어 UI에서는 왼쪽 사이드바 사용자 지정 → 스킬 입니다. Capabilities는 설정(Settings) 쪽에 따로 있습니다.

2순서 체크리스트

  • Settings → Capabilities 에서 Code execution and file creation 토글 ON
  • 사이드바 사용자 지정 → 스킬 이동
  • 목록의 예시(Anthropic 제공) 스킬 중 하나를 ON
  • 새 대화에서 그 스킬이 필요한 요청을 해본다 (호출은 Claude가 알아서 판단)
  • 결과가 나오면 성공 — 스킬을 명시적으로 부를 필요는 없습니다

3플랜 요건

Free · Pro · Max · Team · Enterprise 전 플랜에서 쓸 수 있습니다. 유료 전용 기능이 아닙니다.

  • 공통 조건: 코드 실행(Code execution)이 켜져 있어야 합니다.
  • Team·Enterprise: 조직 소유자가 먼저 조직 설정에서 스킬을 켜야 개인 목록에 나타납니다.
회사 계정인데 스킬 메뉴가 없다면 내 설정 문제가 아니라 조직 설정일 수 있습니다.

5남이 만든 스킬 가져다 쓰기

웹 (claude.ai) — ZIP 업로드

사용자 지정→스킬→+→스킬 만들기→스킬 업로드
  • ZIP 루트에 스킬 폴더가 와야 합니다. 한 겹 더 감싸면 인식되지 않습니다.
  • 최소 요건은 SKILL.md 하나 — 안에 name·description 메타데이터가 있어야 합니다.

Claude Code (터미널)

  • 개인 전체 적용: ~/.claude/skills/<스킬이름>/
  • 프로젝트 한정: .claude/skills/<스킬이름>/
저장소를 받아 그 안의 스킬 폴더를 위 경로에 통째로 두면 됩니다.

⚠️ 막히기 쉬운 곳

스킬 메뉴가 안 보인다 — 대부분 1단계를 안 켠 경우입니다. Settings → Capabilities 에서 Code execution and file creation 을 먼저 켜세요. 회사 계정이면 조직 설정이 원인일 수 있습니다.

Research-Paper 스킬을 웹에 올렸는데 기대와 다르다 — 이 스킬은 저장소가 Codex·Claude Code·Gemini 설치만 안내합니다. 웹 업로드 동작은 공식적으로 보증된 것이 아닙니다. 쓰려면 직접 확인해보고 판단하세요.

excalidraw 스킬이 웹에서 안 돈다 — 정상입니다. 렌더 검증에 Playwright를 쓰는 구조라 터미널(코딩 에이전트) 환경을 전제로 만들어졌습니다.

스킬을 켰는데 안 쓰는 것 같다 — 스킬은 명시적으로 부르는 게 아니라 Claude가 필요하다고 판단할 때 알아서 불러옵니다. 요청을 더 구체적으로 적어보세요.
