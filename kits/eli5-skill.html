ELI5 스킬 쓰는 법

Anthropic 사람들이 사내에서 쓰던 Claude Code 스킬입니다. 무엇을 하는 것인지, 어떻게 깔고 어떻게 쓰는지를 한자리에 놓았습니다.

📄 /eli5 뒤에 궁금한 것을 적으면 됩니다. 아무것도 모르는 사람 기준으로, 큰 그림과 적은 글자로 된 HTML 한 장이 나옵니다.

1무엇을 하나

무엇을 시키나
Explain like I'm someone who knows nothing about this topic, using a HTML artifact with big pictures and few words.
누구 기준으로
그 주제를 전혀 모르는 사람 기준
부르는 법
채팅에 /eli5 <궁금한 것>
나오는 것
큰 그림과 적은 글자로 된 HTML 한 장

2설치

1단계
claude plugin marketplace add anthropics/claude-plugins-community
2단계
claude plugin install eli5@claude-community

커뮤니티 마켓플레이스에서 받습니다. 공식 배포 플러그인이 아닙니다.

3이렇게 씁니다

만든 사람이 든 예시 세 가지입니다. 카드 03 은 이것을 말로 옮긴 것이고, 아래가 원문입니다.

/eli5 how does this module work
/eli5 why did we make this tradeoff
/eli5 what caused this incident

4🔴 이름은 조금 낚시입니다

만든 사람이 다음날 스스로 적었습니다 — 다섯 살에게 설명하라는 뜻이 아닙니다.

중요한 것은 「big pictures, few words」 쪽입니다. 「그 주제를 전혀 모르는 사람」 기준으로 설명해 달라는 프롬프트입니다.
