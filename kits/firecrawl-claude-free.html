🔥 Firecrawl 커넥터
무료로 써보기

Claude 앱의 커넥터 디렉토리에 올라온 Firecrawl 공식 커넥터를 돈 안 들이고 돌려보는 범위를 정리했습니다. firecrawl.dev 공식 요금표·문서와 공식 데모 영상에 있는 것만 적었고, 저희가 직접 돌려본 건 아직 아닙니다(아래 🔎).

무료 플랜
1,000 크레딧 / 월
카드 등록 없음 — 공식 요금표 «No cost, no card»
검색 1회
2 크레딧 (결과 10건)
= 월 약 500회 · 스크랩은 1 크레딧/페이지

1무료로 되는 범위

  • Free 플랜 1,000 크레딧/월, 신용카드 없이 시작 — 공식 요금표
  • 검색 = 2크레딧 / 결과 10건 → 월 약 500회. 한 질문에 검색이 여러 번 돌면 그만큼 빠집니다
  • 비용은 Claude가 아니라 Firecrawl 쪽에서 나갑니다 — 커넥터 요청은 «로그인할 때 고른 팀의 크레딧과 플랜»을 씁니다
  • 더 쓰려면 Hobby 5,000 크레딧 = 월 $16(연 결제 표기)
원문
“1,000 credits / month” · “2 / 10 results” · “1 / page” — firecrawl.dev/pricing
“Requests through this connector use the credits and plan of the team you selected during sign-in.” — docs.firecrawl.dev
💡 무료 범위를 지키는 법 — Claude에게 «검색은 한 번만»처럼 횟수를 같이 적으면 크레딧이 덜 빠집니다. 남은 크레딧은 firecrawl.dev/app 대시보드에서 봅니다.

2연결 절차 — 공식 데모 14초 그대로

  1. Claude 앱(웹·데스크톱·모바일) 대화창의 + 메뉴 → Connectors
  2. Directory 검색창에 firecrawl 입력 → Firecrawl 카드
  3. 카드에서 연결 → Firecrawl 로그인 → 팀 선택 → 승인
  4. 대화에서 그냥 물어봅니다 — 데모 예시 «Get me the latest research papers on fine-tuning with Firecrawl» → Firecrawl 검색이 돌고 결과가 정리됩니다

웹 커넥터는 Claude 전 플랜(무료 포함)에서 쓸 수 있습니다 — support.claude.com. 디렉토리 커넥터는 제3자가 MCP로 만들어 올리고 Anthropic이 일부 검증합니다.

3Claude 기본 웹 검색과 뭐가 다른가

이건 해설 포스트의 주장입니다 — 4.1만 명이 본 포스트(@AM09_21)는 «Claude 기본 웹 검색은 Anthropic 쪽이 크롤해 요약한 개요를 가져오는 쪽에 가깝고, Firecrawl은 원문을 준다»고 적었습니다.

  • Firecrawl 공식 소개: 라이브 인덱스로 최신 웹·논문·코드 저장소를 검색 — 「최신성」과 「출처 선택」이 붙이는 이유
  • Anthropic 공식 문서는 두 검색을 비교하지 않습니다 — 위 비교는 해설자의 판단으로 읽어 주세요
  • 숫자도 마찬가지 — SimpleQA 94.7%는 Firecrawl 자사 벤치마크(7월 22일 자사 블로그, 4,326문항·LLM 채점)
⚠️ «더 정확하다»는 파는 쪽이 잰 숫자입니다. 내 질문으로 기본 검색과 Firecrawl을 한 번씩 돌려 비교해 보고 정하는 게 맞습니다.

🔎 아직 확인 안 된 것

  • 앱 안 디렉토리에 Firecrawl이 실제로 뜨는지 — 공개 디렉토리(claude.com/connectors)엔 없고, 앱 안 페이지는 로그인이 필요해 저희가 직접 확인 못 했습니다. 공식 데모 영상에는 뜹니다
  • 한 질문에 검색이 몇 번 도는지(= 크레딧이 실제로 얼마나 빠지는지) — 직접 돌려봐야 압니다
  • 제3자 사용 후기 — 발표 하루 안에는 공개된 시연·리뷰 영상이 없었습니다
