1i-have-adhd — 답부터 말하게

ayghri/i-have-adhd · 이번 주 +15,924 · 누적 43,649

에이전트 출력 규칙을 10개로 묶습니다. 리포가 적어 둔 설치법은 명령이 아니라 프롬프트입니다 — 쓰는 도구 채팅창에 그대로 붙여 넣으세요.

Install the i-have-adhd skill/plugin from https://github.com/ayghri/i-have-adhd, refer to the repo's AGENTS.md for instructions.
💡 설치 확인: 다시 물어봤을 때 답이 다음 할 일 한 줄로 시작하면 걸린 겁니다. 규칙 원문은 리포의 SKILL.md 에 있습니다.

2ponytail — 코드를 덜 쓰게

DietrichGebert/ponytail · 이번 주 +9,272 · 누적 136,817

클로드 코드 기준으로 두 줄을 따로 보냅니다. 한 번에 붙여 넣으면 설치가 안 됩니다.

/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
⚠️ 막히는 자리: node 가 PATH 에 없으면 오류가 안 나고 조용히 상시 활성화만 꺼집니다. 스킬 자체는 돌아가서 눈치채기 어렵습니다.

3archify — 말하면 구조도

tt-a1i/archify · 이번 주 +10,442 · 누적 60,004

다섯 종류(architecture, workflow, sequence, data-flow, lifecycle)를 혼자 도는 HTML 한 장으로 뽑습니다.

npx skills add tt-a1i/archify -g

커서에서 물어보는 화면 없이 깔려면 이 줄을 씁니다.

npx -y skills add tt-a1i/archify --skill archify --agent cursor --global --copy --yes

4ECC — 한 판으로 까는 쪽

affaan-m/ECC · 이번 주 +8,086 · 누적 257,271

앞의 셋이 스킬 하나라면 이건 묶음입니다. 안내를 따라가는 설치를 권합니다.

npx ecc-universal@2.2.1 setup
⚠️ 막히는 자리: Node.js 18 이상이 필요하고, 플러그인 설치 쪽은 Git 과 Claude Code 2.1 이상이 PATH 에 있어야 합니다. 리포도 안내 설치와 수동 설치를 겹쳐 쌓지 말라고 적어 뒀습니다.
