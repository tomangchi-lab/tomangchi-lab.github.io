GLM-5.3-Flash 바로 쓰기

이름 없이 무료로 돌던 stealth/ox-alpha 가 z-ai/glm-5.3-flash 가 됐습니다. 이 장은 지금 바로 부르는 법부터 놓습니다 — 붙여 넣을 코드, 공식이 권하는 설정값, 지금 물리는 값. 저희가 잰 수치는 뒤에 있습니다.

⚡ 붙여 넣을 모델 문자열 — OpenRouter z-ai/glm-5.3-flash · Z.ai 직접 glm-5.3-flash. 라이선스 MIT, 전체 320B 중 토큰마다 18B 만 작동합니다.

1바로 부르기 — 붙여 넣는 코드

OpenRouter 경로입니다. 키만 있으면 그대로 돕니다.
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "z-ai/glm-5.3-flash",
    "messages": [{"role": "user", "content": "안녕하세요"}],
    "temperature": 1,
    "top_p": 0.95,
    "max_tokens": 32000
  }'
파이썬으로
같은 몸통을 urllib.request 나 openai SDK 의 base_url="https://openrouter.ai/api/v1" 에 그대로 넣으면 됩니다.
Z.ai 로 직접
모델 코드는 glm-5.3-flash, 엔드포인트는 Chat Completion API 입니다. OpenRouter 를 안 거치면 이쪽입니다.

3이미지를 같이 넣을 때

이 모델은 텍스트·이미지·영상 입력을 받습니다.
넣는 자리
messages[].content[] 에 type: "image_url" 블록을 더합니다
URL 이 우선
공식은 이미지 URL 을 권합니다. Base64 데이터 URL 도 받습니다
여러 장
image_url 블록을 여러 개 넣으면 됩니다
"content": [
  {"type": "text", "text": "이 화면을 그대로 코드로 만들어 주세요"},
  {"type": "image_url", "image_url": {"url": "https://example.com/shot.png"}}
]
