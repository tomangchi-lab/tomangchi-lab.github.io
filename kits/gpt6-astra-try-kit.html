3Sites 로 게임·앱 만들기

브라우저에서 바로 돌아가는 3D 카트 레이싱 게임을 만들어 줘. 트랙 하나, 카트 4대, 3바퀴, 방향키 조작, 랩 타임 표시. 만들면 링크를 줘.

4Codex 쓰는 분 — «노트» 켜기

긴 작업에서 컨텍스트가 차면 요약으로 뭉개는 대신 노트를 남기고 옛 창을 검색하는 실험 기능이 Astra 와 같이 나왔습니다. 몇 주 안에 기본값이 된다고 하니 미리 켜 두세요.

  1. Codex 설정 파일 config.toml 을 엽니다.
  2. 설정 레퍼런스에서 실험 기능 항목을 찾아 켭니다 — 항목 이름은 문서 기준으로 확인하세요(발표문은 «config.toml 에서 켠다»까지만 적었습니다).
  3. 모델을 gpt-6-astra 로 두고, 긴 리팩터링 하나를 맡겨 보세요. 중간에 «왜 이 수정이 실패했는지»를 물으면 노트가 있는지 바로 드러납니다.
막히는 자리 — 자동 리뷰(Auto-review)가 거절한 작업을 Astra 는 우회하지 않도록 훈련됐습니다. «안 된다»가 뜨면 우회 프롬프트를 짜지 말고 리뷰 규칙 쪽을 보세요.

9힉스필드에서 Astra 로 영상 만들기 — 힉스필드가 공개한 프롬프트

힉스필드(Higgsfield)는 9월 4~6일에 Astra 가 자기 툴을 조작해 만든 데모를 20편 넘게 올렸습니다. 뉴욕 3D · 포토샵 배경화 · 아이 동화 · 마인크래프트 화면이 그중 넷입니다. 대부분은 결과만 보여 주는데, 프롬프트를 통째로 공개한 것이 두 건 있습니다. 아래는 그 원문과 저희가 옮긴 한국어입니다 — 힉스필드 팀이 직접 낸 결과이고, 같은 프롬프트로 같은 결과가 나온다는 뜻은 아닙니다.

경로 ① ChatGPT 에 힉스필드를 붙이고 Astra 에게 시키기

  1. ChatGPT 의 플러그인 디렉터리에서 Higgsfield 를 찾아 Add → 힉스필드 계정으로 로그인합니다. API 키는 필요 없습니다.
  2. 새 대화에서 모델을 GPT-6 Astra 로 두고 힉스필드를 도구로 고른 뒤, 아래처럼 단계를 번호로 적어 넘깁니다. 힉스필드 데모는 전부 이 꼴입니다 — 한 문장이 아니라 번호 목록입니다.

Ⓐ 캐릭터 → 3D → 블렌더 → 만화 (힉스필드 원문 · 30분 걸렸다고 적혀 있습니다)

원문 — Take control of my computer using GPT-6 Astra and do the following: 1. design a character concept using Higgsfield Soul 2.0, 2. build a textured 3D model of it, 3. import it into Blender, 4. retopologize the mesh, 5. create a UV map, 6. build a character rig, 7. evaluate how production-ready the model is, 8. redo previous steps if you're not satisfied with results, 9. and then turn it into a cartoon using Seedance 2.5 on Higgsfield
GPT-6 Astra 로 내 컴퓨터를 조작해서 아래를 순서대로 해 줘.
1. Higgsfield Soul 2.0 으로 캐릭터 콘셉트를 디자인하고
2. 그걸 텍스처 입힌 3D 모델로 만들고
3. Blender 로 불러와서
4. 메시를 리토폴로지하고
5. UV 맵을 만들고
6. 캐릭터 리그를 짜고
7. 이 모델이 실제 제작에 쓸 만한지 평가하고
8. 마음에 안 들면 앞 단계로 돌아가서 다시 하고
9. 끝나면 Higgsfield 의 Seedance 2.5 로 만화로 만들어 줘.

Ⓑ 두개골 사진 → 얼굴 복원 → 포토리얼 렌더 (힉스필드 원문)

원문 — Show all the process, how you find it, how you made a detailed 3d object and put it in Higgsfield. 1. Search open sources for reference photos of ancient Scythian skulls (archaeological finds, museum collections). 2. Model this skull in Blender based on the references, make it detailed and accurate. 3. Reconstruct the face over the skull: add skin, eyes, full facial features and hair – a forensic facial reconstruction of what the person looked like. Keep accuracy of original image. 4. Switch to the Higgsfield tab and run Seedream to visualize the final 3D object as a photoreal render.
찾는 과정, 3D 로 만드는 과정, Higgsfield 에 넣는 과정을 전부 보여 줘.
1. 공개 자료(발굴 보고·박물관 소장품)에서 고대 스키타이인 두개골 참고 사진을 찾고
2. 그 참고를 바탕으로 Blender 에서 두개골을 정확하고 세밀하게 모델링하고
3. 두개골 위에 얼굴을 복원해 줘 — 피부·눈·이목구비·머리카락까지, 법의학 얼굴 복원처럼. 원본 사진의 정확도를 지켜.
4. Higgsfield 탭으로 넘어가서 Seedream 으로 완성된 3D 오브젝트를 포토리얼로 렌더해 줘.
공통 꿀팁 — 두 프롬프트 다 «과정을 보여 줘»·«마음에 안 들면 다시 해» 가 들어 있습니다. Astra 는 중간 결과를 스스로 평가하고 되돌아가는 모델이라, 그 한 줄이 있어야 8단계·4단계가 끝까지 갑니다.

경로 ② 힉스필드 안에서 — 3D Jutsu 의 모델을 Astra 로

  • 힉스필드 3D Jutsu(프롬프트 → 편집 가능한 3D 장면 → 영상 렌더)의 LLM 목록에 GPT 6 Astra 가 있습니다. 9월 5일 힉스필드 블로그 기준 메시지당 약 17 크레딧이고, 기본값 Auto 는 무료입니다. 뉴욕 3D 데모가 이 경로입니다.
  • 순서: 장면을 글로 적기 → (선택) 참고 이미지 붙이기 → 모델·길이(1~60초)·비율 고르기 → Generate → 뷰포트에서 물체·조명·카메라 손보기 → 같은 채팅에서 «렌더해 줘».
  • Soul 2.0 · Seedance 2.5 · Seedream 은 힉스필드의 유료 생성 모델입니다. 크레딧 값은 힉스필드 요금 페이지에서 확인하세요 — 이 킷엔 옮기지 않았습니다.
