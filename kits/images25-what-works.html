🎨 ChatGPT Images 2.5
새 기능 4개 · 어디서 되나

오픈에이아이가 2026년 9월 9일 새벽(한국시간) Introducing ChatGPT Images 2.5 를 올렸습니다. 새로 붙은 기능은 이미지 위 댓글 · Sketch · 템플릿 · 프롬프트 공유 넷입니다. 이 킷은 넷을 지금 내 ChatGPT 에서 부르는 법으로 펴 놓은 것이고, 그보다 중요한 «그 기능이 어느 화면에서 되나»를 공식 문서 둘로 대조해 둔 것입니다. 영문 인용은 공식 원문 그대로입니다.

1새로 붙은 기능은 넷입니다

«부르는 법» 칸은 공식 문구가 말한 조작만 적었습니다. 화면 위치는 판마다 다를 수 있습니다.

기능부르는 법공식 원문
이미지 위 댓글만든 이미지를 열고 고칠 자리를 짚어 댓글을 붙입니다“place comments directly on images for more focused editing”
Sketch채팅창에 @Sketch 를 입력해 부르고, 그린 뒤 원하는 결과를 글로 덧붙입니다“just type “@Sketch” in ChatGPT”
템플릿Poster·Merch 같은 형식을 먼저 고르고 시작합니다“you can choose a template like “Poster” or “Merch””
프롬프트 공유쓴 프롬프트를 그림과 같이 넘겨 다른 사람이 제 사진으로 다시 돌리게 합니다“share prompts you’ve used to let others try your ideas with their own photos and details”
넷 중 셋(댓글 · Sketch · 템플릿)은 «만들기 전»이 아니라 «만든 뒤에 고치는» 자리에 붙었습니다. 이번 판의 무게가 그쪽에 실려 있습니다.

2🔴 «어디서 되나» — 공식 문서 둘이 다르게 적습니다

이 킷에서 가장 쓸모 있는 칸입니다. 발표 글은 플랫폼을 달지 않았고, 도움말은 «댓글»과 «스케치»를 모바일 앱 절에만 적었습니다. 웹 편집기 절의 버튼 목록에는 그 둘이 없습니다.

문서무엇이 적혀 있나원문
발표 글플랫폼 한정 없음“You can also now place comments directly on images for more focused editing”
도움말 · 모바일 절댓글 있음“On the ChatGPT mobile app, select an image … You can edit the image or add comments.”
도움말 · 모바일 절스케치 있음“On the ChatGPT mobile app, you can draw a sketch and use it with written instructions to create an image.”
도움말 · 웹 편집기 절버튼 목록에 댓글이 없음Select / Aspect ratio / Undo·Redo / Cancel / Save 다섯 줄뿐
🔴 그래서 «웹에서는 안 된다»가 아닙니다. 두 공식 문서가 서로 다르게 적고 있고, 어느 쪽이 현행인지 바깥에서 가를 방법이 없다는 것까지가 확인된 사실입니다. 도움말이 스케치도 모바일 절에만 둔 걸 보면 «도움말이 모바일부터 갱신되는 중»일 수도 있지만, 그건 추측이라 여기에 결론으로 적지 않습니다.
실용적인 대처 — 댓글 편집이 안 보이면 폰 앱에서 먼저 열어 보세요. 공식 문서가 그 자리를 확실히 적어 둔 유일한 화면입니다.

3무엇이 좋아졌다고 적혀 있나

비교급·상한 표현을 원문 그대로 옮겼습니다. «항상 그렇다»로 올리지 않았습니다.

주장원문
짚은 곳만 바뀐다“Images 2.5 is better at editing only what you’ve asked for, while keeping the rest of the details the same”
여러 번 고쳐도 안 무너진다“Earlier changes are more likely to stay consistent, and each new edit builds on the work you’ve already done without degrading image quality over time.”
속도“reduced image generation latency by up to 50% compared with Images 2.0”
규모“Every week, people create more than 3 billion images across ChatGPT Images and the GPT‑Image models in the API.”
“better at” · “more likely to” · “up to” — 셋 다 비교급이거나 상한입니다. 평균이 아니라 «가장 잘 됐을 때»를 말하는 문장이라는 뜻입니다.

4API 에도 두 모델이 같이 나왔습니다

모델공식 설명
Flare“GPT-Image-2.5 Flare brings the same quality, editing, and speed improvements”
Sunburst“GPT-Image-2.5 Sunburst adds precision for detailed creative work, with longer generation times.”
둘의 갈림길은 «정밀함이냐 속도냐»입니다 — Sunburst 는 더 정밀한 대신 더 오래 걸린다고 공식 글이 직접 적었습니다.

5이 킷이 하지 않은 것

  • Images 2.5 를 저희가 직접 써 보지 않았습니다. 이 문서의 모든 값은 오픈에이아이가 발표 글·도움말·X 포스트에 적은 문구입니다.
  • «댓글 편집»이 실제로 짚은 자리만 바꾸는지 재현하지 않았습니다. 공식 화면과 공식 문구까지가 근거입니다.
  • API 두 모델의 가격 수치는 여기 없습니다. 발표 글의 «Pricing and availability» 절은 롤아웃 범위 한 문장뿐이고, 별도 요금 페이지는 이 회차에 열지 않았습니다.
  • 제3자 벤치마크 순위는 넣지 않았습니다. 공식 글에 없는 수치라 저희가 조회하지 않았습니다.
  • 한국어 UI 에 언제·어떻게 반영되는지는 공식 문구에 없습니다.
