🗂️ 마누스 백업 3단계
— 지우기 전에 이것만

마누스가 독립 회사로 돌아가면서 일부 계정의 데이터를 지웁니다. 전원은 아니고, 대상이면 메일·앱 알림이 와요.
공식 헬프센터 문서에 적힌 것만 순서대로 옮겼습니다.

① 백업 마감 (한국시간)
8/23 08:59
원문 8/23 07:59 SGT
무료 캠페인 종료 (한국시간)
8/26 00:59
원문 8/25 23:59 SGT

1내 계정이 대상인지 확인 (30초)

가장 빠른 방법은 알림 확인입니다. 마누스는 대상 여부를 개별 통지합니다.

  1. 마누스 앱 안의 공지(in-app notice)를 엽니다 — 대상이면 삭제 예정 안내가, 아니면 "영향 없음" 안내가 떠 있습니다.
  2. 가입 메일함을 확인합니다. 대상자에게만 메일이 갑니다 — 대상이 아니면 메일 자체가 오지 않습니다.
  3. 계정이 여러 개거나 팀 계정 + 개인 계정이면 각각 따로 확인해야 합니다.
⚠️ 애플 ID·페이스북으로 가입했다면 메일이 안 옵니다. 마누스가 그 계정의 이메일 주소를 갖고 있지 않아서예요. 앱 내 알림만 보고 판단해야 합니다.
공식 원문 — “We’ll notify affected users in the Manus app and by email. For users who registered for Manus using an Apple ID or Facebook account, please check your in-app notifications, as we do not have your email address.” (manus.im/blog)

💡 어느 데이터가 지워지나 — 2025년 12월 29일(태평양시 0시) 이후에 만들거나 수정한 태스크. 계정 유형과 상관없이 이 구간이 대상입니다.

대상이라면, 유형까지 봐야 합니다

  • Type A · B — 계정을 인수일(2025/12/29) 전에 만들었고, 그 뒤로 계정 이메일·사용자 정보를 바꾼 적이 없다.
    → 계정은 남습니다. 태스크 데이터만 백업하면 됩니다.
  • Type C — 계정을 인수일 당일이나 그 이후에 만들었거나, 그 뒤에 계정 이메일·사용자 정보를 바꿨다.
    → 계정 자체가 삭제됩니다. 계정 정보 백업을 반드시 먼저 받아야 하고, 그게 없으면 태스크도 복원 못 합니다.

A와 B는 구독 시작 시점으로 갈리는데, 백업·복원 절차는 A·B가 같습니다 — 그래서 이 킷은 둘을 묶어 씁니다.

2백업 — 8/23 08:59(한국시간)까지

웹 또는 데스크톱 버전에서 하세요. 마누스가 권장하는 방식입니다.

먼저 확인할 것

  • 페이스북 로그인만 쓰고 있다면 — 계정 설정에서 다른 로그인 수단이나 이메일을 먼저 추가해야 백업이 됩니다. 서비스 변경 후 페이스북 로그인은 막힙니다.

순서 체크리스트

  1. 마누스에 로그인합니다.
  2. 홈에서 Data Backup Tool(데이터 백업 도구)을 엽니다.
  3. Type C 계정이면 안내에 따라 Account Info Backup(계정 정보 백업)을 먼저 생성·다운로드합니다. 이게 없으면 나중에 계정 복원이 안 됩니다. Type A·B는 이 단계가 없습니다.
  4. Task Data Backup(태스크 데이터 백업)을 생성합니다 — 백업할 태스크를 골라서 선택할 수 있습니다.
  5. 내보낼 곳을 고릅니다. 용량이 커서 구글 드라이브 / 원드라이브 연동(OAuth)을 강력 권장합니다.
  6. 완료 확인이 뜨면 클라우드나 로컬 폴더를 직접 열어 파일이 실제로 있는지 확인합니다.
💡 백업 파일 2종 — 계정 정보 백업은 10MB 이하로 메일 첨부로도 옵니다. 태스크 데이터 백업은 수십MB~수십GB이고, 패키지 하나가 4GB를 넘으면 쪼개집니다(8GB면 4GB짜리 2개). 쪼개진 조각을 전부 보관하세요.
⚠️ 백업은 그 시점의 스냅샷입니다. 백업 후에 새로 작업했으면 8/23 08:59 전에 다시 백업해야 합니다.
⚠️ 백업 파일을 이름 바꾸거나 옮기거나 수정하지 마세요 — 못 쓰게 됩니다.

👥 팀 계정은 팀 소유자만 백업할 수 있습니다. 팀원은 plaintext export만 되는데 그건 복원에 못 씁니다 — 소유자에게 백업했는지 확인하세요. 개인 계정과 팀 소유자를 겸하면 백업을 두 번 해야 합니다.

3복원 — 8/25 09:00(한국시간)부터

그 사이 8/23 09:00 ~ 8/25 09:00(한국시간)에는 대상 계정이 마누스에 접속되지 않습니다. 데이터 삭제가 진행되는 구간이에요.

  1. Type A·B — 로그인하면 홈에 Task Data Restoration Tool이 자동으로 뜹니다. 최신 태스크 데이터 백업을 올리면 끝.
  2. Type C — 계정 복원 사이트에 Account Info Backup을 먼저 올려 계정을 되살린 뒤, 로그인하고 태스크 데이터를 복원합니다.
⚠️ 복원은 딱 한 번만 됩니다. 백업 패키지를 여러 개 한꺼번에 올리면 중복을 걸러 합쳐주니, 가진 조각을 다 모아서 한 번에 올리세요. 나눠서 두 번은 안 됩니다.
💡 마누스로 배포한 웹사이트는 8/23 09:00(한국시간)부터 접속이 끊기고, 내가 복원해야 자동으로 다시 살아납니다 — 언제 복원할지는 내가 정하는 거라 마감이 따로 없습니다.
💡 서드파티 커넥터는 복원되지만 토글은 손으로 다시 켜야 합니다.

복원 시 “Account Information Inconsistent” 오류가 뜨면 백업 파일과 같은 계정으로 로그인했는지 확인하세요.

⚠️ 자주 막히는 곳

  • 클라우드 연동 인증 실패 → 네트워크·클라우드 로그인 상태·남은 용량을 확인하고 재시도. 계속 실패하면 에러 화면을 캡처해 고객지원에 보내세요.
  • 백업 파일이 안 보임 → 클라우드 휴지통과 버전 기록, 로컬 휴지통을 먼저 보고, 맞는 클라우드 계정인지 확인. 진짜 없어졌으면 백업 기간 안에 다시 만들어야 합니다 — 기간이 끝나면 새 백업은 불가능합니다.
  • Type C인데 백업을 못 했다 → 8/23 08:59 전까지 안 하면 계정 정보 백업만 자동 생성돼 메일로 옵니다. 태스크 데이터는 자동으로 안 됩니다 — 작업물을 지키려면 직접 해야 합니다.
  • “나는 대상이 아닌 것 같은데?” → 마누스는 어느 나라·어느 조건이 대상인지 공개하지 않았습니다. 추측하지 말고 메일·앱 알림으로만 판단하세요.
