내 스킬 만들기 체크리스트

Notion 스킬은 따로 만드는 물건이 아니라 페이지입니다. 만드는 경로와 자동 실행 조건, 밖으로 들고 나가는 법을 한자리에 놓았습니다.

📄 스킬은 페이지입니다. 그래서 정리·공유·권한이 다른 페이지와 똑같이 돌아갑니다 — 새로 배울 규칙이 없습니다.

1만드는 네 갈래

이미 있는 페이지로 만들기
페이지 위 ••• → Use as a Skill
새로 만들기
사이드바 Library → Skills 탭 → + Add a Skill
설정에서 찾기
Settings → Notion AI → Skills
채팅에서 부르기
Notion Agent 채팅에서 / 입력 → 스킬 목록
되돌리기 (해제)
페이지 위 ••• → Unset page as skill 페이지와 내용은 그대로 남는다

2🔴 자동으로 돌게 하려면

페이지면 다 스킬이 되지만, 자동으로 도는 것은 아닙니다.

자동으로 돌게 하려면
설명(description)이 있어야 한다
설명은 어디서 생기나
스킬 데이터베이스 안에 있을 때만 생긴다
수동으로 고정하려면
Use automatically 토글을 끈다

3밖으로 들고 나가기

스킬 페이지에서 내 컴퓨터 폴더로 내려받습니다. SKILL.md 와 승인된 파일이 함께 갑니다.
