1무엇을 해주나 · 어떻게 돌아가나 · 쓰면 좋은 사람

mutonby/openshorts · 누적 별 4,599 · 포크 1,126 · 2026-09-16 조회

무엇을 해주나

도구 셋이 한 대시보드에 있습니다 — Clip Generator(긴 영상 → 9:16 쇼츠), AI Shorts(AI 배우가 나오는 UGC 광고), YouTube Studio(제목·썸네일·설명).

어떻게 돌아가나

  • Clip Generator — 음성을 받아 적고(faster-whisper), 장면 경계를 잡은 뒤 Gemini 가 뜰 만한 구간을 3~15개(각 15~60초) 고릅니다. 얼굴을 따라 세로로 자르고 자막을 입힙니다. 두 사람이 나오면 위아래로 쌓고 자막을 이음새에 둡니다.
  • AI Shorts — 사이트를 읽고(또는 설명 한 줄) 훅·문제·해결·행동 순서로 대본을 쓰고, Flux 2 Pro 로 배우를 만들고, ElevenLabs 로 목소리를 입히고, Hailuo 2.3 Fast + VEED Lipsync 로 입을 맞춥니다. B롤과 자막을 붙여 FFmpeg 로 합칩니다.
  • YouTube Studio — 제목 후보 10개와 다듬기 채팅, 얼굴을 넣은 썸네일, 챕터 시간이 든 설명을 만듭니다.

쓰면 좋은 사람

  • 팟캐스트·라이브 같은 긴 영상을 매주 쇼츠로 잘라 올리는 사람
  • 작은 가게·쇼핑몰처럼 제품 광고 영상을 여러 벌 돌려 보고 싶은 사람
  • Docker 를 한 번이라도 띄워 본 사람 — 설치가 명령 네 줄입니다

2설치 방법

  1. Docker 와 Docker Compose 를 먼저 깝니다. 램은 8GB 이상이어야 합니다.
  2. 리포를 받아 폴더로 들어갑니다.
  3. 설정 파일을 복사합니다. S3 백업을 쓸 때만 안을 고치면 됩니다.
  4. 띄웁니다. 처음에는 이미지를 짓고 모델을 받느라 오래 걸립니다.
  5. 브라우저로 대시보드를 엽니다.
git clone https://github.com/mutonby/openshorts.git
cd OpenShorts
cp .env.example .env
docker compose up --build
http://localhost:5175

키 넣기

  1. 대시보드 Settings 에 들어갑니다.
  2. Gemini · fal.ai · ElevenLabs · Upload-Post 키를 넣습니다. 키는 브라우저 쪽에서 암호화돼 서버에 저장되지 않습니다.
키필요한 곳요금
Gemini모든 AI 기능무료 발급
fal.aiAI Shorts (배우·영상·립싱크)쓴 만큼
ElevenLabs목소리·더빙무료 구간 있음
Upload-Post틱톡·인스타·유튜브 바로 올리기월 10회 무료
💡 쇼츠 자르기만 쓸 거라면 fal.ai 키는 없어도 됩니다 — fal.ai 는 AI Shorts 에만 필요합니다.

3구글 키 없이 돌리기 (선택)

클립 파이프라인에서 밖으로 나가는 호출은 구간 고르기 하나이고, 영상이 아니라 대본만 보냅니다. 내 컴퓨터의 Ollama 같은 서버로 돌리면 전부 안에서 끝납니다. .env 에 두 줄을 넣습니다.

LLM_BASE_URL=http://host.docker.internal:11434/v1
LLM_MODEL=qwen2.5:14b

Ollama 는 기본 문맥이 짧아 조용히 잘립니다. 이 값으로 띄우세요.

OLLAMA_CONTEXT_LENGTH=16384
⚠️ 화면을 봐야 하는 일(레이아웃 자동 고르기 · 화면 속 내용 감지 · 말 없는 영상)은 여전히 Gemini 가 필요합니다. 키가 없으면 얼굴 따라가기 자르기로 돌아가고, 말 없는 영상은 실패 메시지를 냅니다.

4막히는 자리

  • 느리다 — 기본 이미지는 CPU 전용이라 8분짜리 영상 하나에 5~8분이 걸립니다. NVIDIA 그래픽카드가 있으면 README 5절의 GPU 설정으로 줄일 수 있습니다.
  • 폴더 이름 — 받은 폴더는 openshorts 인데 README 는 cd OpenShorts 로 적혀 있습니다. 대소문자를 가리는 리눅스·맥에서는 cd openshorts 로 들어가세요.
  • AI Shorts 가 안 된다 — fal.ai 키가 없으면 배우·영상·립싱크 단계가 돌지 않습니다.
  • 업로드 한도 — 파일은 2GB 까지입니다.
  • 광고로 쓸 영상 — 만든 영상과 아바타는 공개 갤러리에 저장된다고 README 에 적혀 있습니다. 내놓기 전의 제품이면 이 부분부터 확인하세요.

5설치 확인

  • docker compose up --build 가 멈추지 않고 돈다
  • http://localhost:5175 에서 대시보드가 열린다
  • Settings 에 Gemini 키를 넣었다
  • 짧은 영상 하나를 Clip Generator 에 올려 클립이 나온다
  • AI Shorts 를 쓸 거면 fal.ai 키까지 넣고, 저가 모드로 먼저 한 편 만들어 본다

GPU 를 붙였다면 이 줄로 컨테이너가 그래픽카드를 보는지 확인합니다.

docker exec openshorts-backend nvidia-smi -L
