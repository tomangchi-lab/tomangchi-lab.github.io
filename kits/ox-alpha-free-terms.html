Ox Alpha 쓰는 법 + 무료 조건 대조표

만든 곳을 밝히지 않은 모델 Ox Alpha 가 무료로 열렸습니다. 바로 쓸 수 있는 명령과, 쓰기 전에 알아 둘 조건을 한자리에 놓았습니다.

⚡ 모델 이름에 stealth/ox-alpha 만 적으면 됩니다. 카드 등록도 잔액도 필요 없습니다.

0바로 쓰는 법

1. 가입
openrouter.ai — 카드 등록 없이 됩니다.
2. 키 발급
Keys 메뉴에서 발급. 무료 모델은 잔액이 없어도 호출됩니다.
3. 모델 지정
쓰던 코드에서 모델 이름만 stealth/ox-alpha 로 바꾸면 그대로 돕니다.
curl
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -d '{"model": "stealth/ox-alpha", "messages": [{"role":"user","content":"..."}]}'
Python (OpenAI SDK)
client = OpenAI(base_url="https://openrouter.ai/api/v1", api_key=KEY)
client.chat.completions.create(model="stealth/ox-alpha", messages=[...])
🔴 재시도는 넣으세요
429(일시 제한)가 자주 뜹니다. 재시도하면 통과하지만, 없으면 작업이 임의로 끊깁니다.
🔴 max_tokens 는 넉넉히
추론 분량이 상한에 포함됩니다. 낮게 주면 답이 시작되기도 전에 잘려 빈 응답이 옵니다(저희가 12000 에서 겪었습니다).

2항목별로 갈리는 지점

보관하는가
① 보관한다 ↔ ③ 보관하지 않는다 — 정반대입니다.
학습에 쓰는가
① 쓰지 않는다 ↔ ② 학습 제공이 무료의 대가다
언제까지 무료인가
① 밝히지 않음 ↔ ③ 일주일
②는 “limited period of time” 과 “with or without notice to you”(사전 통보 없이 종료 가능) 만 적혀 있습니다.
한도가 있는가
①·② 표기 없음 ↔ ③ “near unlimited”

약관 본문은 7월 6일자 그대로이고, 예외는 안내문과 공지 글로만 밝혀져 있습니다. 어느 쪽이 우선하는지는 공개된 자료로 확인되지 않습니다.
