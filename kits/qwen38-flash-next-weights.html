Qwen3.8-Flash-Next 받기·조건 한 장

Qwen4 구조를 미리 보는 오픈 웨이트가 8월 26일 풀렸습니다. 받는 곳, 파일 크기, 공식 실행 명령, 라이선스 조건, 그리고 지금 어디서 써볼 수 있는지 실측한 것을 한 장에 놓았습니다.

1이 편의 이름 둘

본문 카드는 Flash-Next 만 말합니다. 아래가 원문 기준의 구분입니다.
Qwen3.8-Flash-Next
오픈 웨이트. Hugging Face · ModelScope 에 8월 26일 공개. 멀티모달 MoE, «Qwen4 에 쓰일 구조의 이른 미리보기».
Qwen3.8-Flash
프로덕션 판. Flash-Next 기반에 1M 문맥 기본·내장 도구를 얹어 QwenCloud API 로 제공될 이름. 공식 블로그 표기는 «API coming soon»(1M 입력 0.16 달러 · 출력 0.47 달러) — 이 킷 작성 시점(8월 26일 22:20 기준)엔 열리지 않았습니다.
규모
본체 125B + N-gram 임베딩 51B, 토큰당 활성 6B (MTP 4B 별도). 문맥 262,144 기본, YaRN 으로 1,000,000 까지.
구조 4가지
GDN + QSA 하이브리드 어텐션(4층 중 3층 GDN·1층 QSA) · Gated Residual(4갈래) · N-gram Embedding(호스트 메모리 프리페치) · Muon 옵티마이저.
비용
Qwen3.7-Plus(397B·활성 17B) 대비 활성 파라미터 1/3 · 학습 토큰 1/3 · 학습 FLOPs 약 1/9(기술보고서 Abstract). 1M 문맥 프리필 처리량 8.6배(프리픽스 캐시 90% 조건).

3돌리는 명령 (공식 README)

Hugging Face 모델 카드·GitHub README 의 quickstart 를 그대로 옮겼습니다. 저희도 아직 안 돌려봤어요 — 360GB 급 가중치라 128GB 급 통합 메모리나 다중 GPU 가 필요합니다.
# vLLM
pip install vllm
vllm serve Qwen/Qwen3.8-Flash-Next --port 8000

# SGLang
pip install sglang
python3 -m sglang.launch_server --model-path Qwen/Qwen3.8-Flash-Next
기본 동작
thinking 모드가 기본 on(enable_thinking · preserve_thinking · reasoning_effort 로 제어). 끄려면 chat_template_kwargs: {"enable_thinking": false}.
권장 샘플링
thinking: temperature 1.0 · top_p 0.95 · top_k 20 / non-thinking: temperature 0.7 · top_p 0.80 · top_k 20 · presence_penalty 1.5
1M 문맥
YaRN 설정(rope_type: yarn · factor 4.0 · original_max_position_embeddings 262144)을 넘겨야 합니다. 짧은 문맥 위주면 켜지 말라는 것이 공식 안내.
